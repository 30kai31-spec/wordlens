# 📖 WordLens — 英単語学習サポートアプリ

英字新聞などの英文から知らない単語を簡単にデータベース化し、エビングハウスの忘却曲線に基づいた復習で語彙力を定着させるWebアプリです。

---

## 🚀 自分用にデプロイする方法

このアプリは **[Genspark](https://www.genspark.ai/)** を使って無料でデプロイできます。  
デプロイすると**自分専用のデータベース**が自動生成され、他の人のデータと混ざりません。

### 手順

1. **[Genspark](https://www.genspark.ai/) にアクセスしてアカウントを作成**（無料）

2. **新しいプロジェクトを作成**
   - 「Create Project」または「新規プロジェクト」をクリック

3. **ファイルをアップロード**  
   以下のファイルをすべてアップロードしてください：
   ```
   index.html
   articles.html
   review.html
   vocabulary.html
   css/style.css
   js/app.js
   ```
   > ⚠️ `css/` と `js/` フォルダ構造を保ったままアップロードしてください

4. **Publishタブからデプロイ**
   - 「Publish」タブを開く
   - 「Publish Access」を**公開（Public）**に設定
   - 「Publish」ボタンをクリック

5. **完了！**  
   発行されたURLにアクセスすると、自分専用のWordLensが使えます。

## ✅ 機能一覧

### ダッシュボード（`index.html`）
- 登録英文数・総単語数・習得済み数の統計表示
- 復習予定単語がある場合のバナー通知
- 最近追加した単語の一覧表示

### 英文一覧（`articles.html`）
- 英文（タイトル・出典・本文）の追加・編集・削除
- タイトル・本文のキーワード検索
- ページネーション（10件/ページ）
- **英文読み込みビュー**
  - 単語をタップして選択 → 一括でデータベースに追加
  - 複数単語をなぞってハイライト → 熟語・フレーズとして追加
  - 登録済みの単語は点線下線で表示
  - 翻訳API（MyMemory）で日本語訳を自動取得
  - 文脈（コンテキスト文）も自動保存

### 復習（`review.html`）
- **忘却曲線コース**：次回復習日が来た単語のみ出題
- **ランダムコース**：全単語からランダムに最大10問出題
- フリップカード形式（タップで裏返し）
  - 表面：単語のみ
  - 裏面：日本語訳・出典記事・コンテキスト・メモ欄
- 「覚えた！」「覚えていない」で復習記録を更新
  - 6回「覚えた」で習得済みに自動昇格
- セッション終了後に結果画面（正答率・覚えた数）を表示

### 単語データベース（`vocabulary.html`）
- 登録済み全単語の一覧表示・検索
- フィルター：すべて / 🔔要復習 / ✅習得済み / 🆕未学習
- 並び替え：新着順 / 登録順 / A→Z / 復習回数
- 単語詳細モーダル
  - 日本語訳の表示・編集
  - コンテキスト表示（単語をハイライト）
  - メモの編集・保存
  - 復習回数・最終復習日・次回復習予定日
  - 習得済みトグル・単語削除

## 🔔 忘却曲線スケジュール

「覚えた！」を押すたびに復習間隔が延びます：

```
1回目 → 1日後
2回目 → 3日後
3回目 → 7日後
4回目 → 14日後
5回目 → 30日後
6回目 → 90日後（習得済みへ昇格）
```

## 📊 データモデル

### `articles` テーブル
| フィールド | 型 | 説明 |
|-----------|-----|------|
| `id` | text | 一意識別子（UUID） |
| `title` | text | 記事タイトル |
| `content` | rich_text | 英文本文 |
| `source` | text | 出典（新聞名など） |
| `added_at` | datetime | 追加日時 |

### `vocabulary` テーブル
| フィールド | 型 | 説明 |
|-----------|-----|------|
| `id` | text | 一意識別子（UUID） |
| `word` | text | 英単語・フレーズ |
| `japanese_meaning` | text | 日本語訳 |
| `article_id` | text | 所属記事ID |
| `article_title` | text | 所属記事タイトル |
| `context` | text | 単語が含まれる文（コンテキスト） |
| `memo` | text | ユーザーメモ |
| `review_count` | number | 復習回数 |
| `last_reviewed_at` | datetime | 最終復習日時 |
| `next_review_at` | datetime | 次回復習予定日時 |
| `is_mastered` | bool | 習得済みフラグ |
